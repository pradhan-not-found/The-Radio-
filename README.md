# 📻 The Radio (Devi Paksha Edition)

A highly realistic, interactive web-based vintage radio simulator featuring stunning 3D-styled UI, working FM/AM tuning mechanics, mechanical sound effects, and a modern Spotify-like digital playlist interface. Built exclusively for a premium auditory and visual experience.

## ✨ Features

- **Realistic Physical Simulation**: Fully interactive knobs with knurled metal textures, dynamic shadows, and heavy mechanical click/thud sounds.
- **Tuning Dial Mechanics**: Authentic FM/AM scale display featuring a moving red indicator needle that smoothly sweeps across frequencies.
- **Signal Processing & Static**: Real-time signal strength simulation with authentic radio static (white/pink noise) using Web Audio API when untuned.
- **Digital Mode & Spotify-style Playlists**: Switch from analog FM to a modern digital player featuring curated playlists, sleek dropdowns, and an immersive full-screen modal interface.
- **Responsive Design**: Flawless scaling from large desktop monitors down to mobile screens using smart CSS transforms.
- **Built with React & Vite**: Lightning-fast performance and modern development tooling.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pradhan-not-found/The-Radio-.git
   cd The-Radio-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Technology Stack

- **React 18** - UI Component Architecture
- **Vite** - Build Tooling & Dev Server
- **CSS3** - Advanced styling (Gradients, Shadows, Flexbox)
- **Web Audio API** - Custom synthesized radio static and mechanical sounds
- **React YouTube** - Headless YouTube iframe integration for the digital playlist
